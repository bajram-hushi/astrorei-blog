# ReiLabs Productization Plan (April 2026)

## 1) Most Needed Missing Features

### Critical (Needed to Sell)
1. Post edit/delete with version history
- Why: Companies require content lifecycle control for accuracy and compliance.

2. Admin dashboard (user management + moderation)
- Why: Buyers need owner-level controls, role assignment, and offboarding.

3. Organization and role model
- Why: B2B product needs org-level permissions, not only user-centric access.

4. Search, tags, and filters
- Why: Internal knowledge loses value without discoverability.

5. Audit logs
- Why: Teams need accountability for content/admin actions.

### High Priority (Needed for Retention)
1. Drafts, autosave, and scheduling
2. Analytics dashboard (engagement + investment outcomes)
3. Integrations (Slack/Teams, webhooks/API, CSV import/export)
4. Comment moderation and anti-abuse controls
5. Investment governance (caps, policy rules, anti-gaming)

### Growth Priority (Needed for Larger Deals)
1. SSO/SAML + SCIM
2. Advanced permissions (confidential spaces/content)
3. White-label branding
4. Compliance exports (GDPR/right-to-delete)

## 2) Why Companies Should Buy ReiLabs

1. It turns internal writing into prioritization.
- Blogs communicate. ReiLabs helps teams discuss, evaluate, and invest in ideas.

2. It offers strong SMB cost efficiency.
- Lower infrastructure and operating cost than many internal comms SaaS tools.

3. It creates a measurable innovation loop.
- Post -> discussion -> scoring/investment -> clearer product/strategy decisions.

4. It is extensible.
- Modern stack (Next.js + Supabase) supports custom workflows and integrations.

## 3) ReiLabs vs BlogIn (blogin.co)

| Dimension | ReiLabs | BlogIn |
|---|---|---|
| Internal blogging | Yes | Yes |
| Comments/discussion | Yes (nested + voting) | Yes |
| Idea investment workflow | Yes (differentiator) | No native equivalent known |
| AI-assisted idea scoring | Yes | Not a core differentiator |
| Admin/roles | Partial (needs expansion) | Mature |
| Search/discovery | Missing (must add) | Mature |
| SSO/SCIM | Missing today | Mature |
| Integrations ecosystem | Limited today | Broad |
| Security/compliance packaging | Early stage | Mature |
| Cost posture | Potential low-cost advantage | Established SaaS pricing |

Positioning takeaway:
- Do not compete as "just another internal blog." Compete as an innovation operating system: internal publishing + idea investment + AI support.

## 4) 12-Week Product Plan

### Phase 1 (Weeks 1-4): Commercial Baseline
1. Add post edit/delete + version history.
2. Build admin dashboard with role management.
3. Add org boundary model and role-aware authorization.
4. Implement audit logs.
5. Add abuse/rate-limit protections.

### Phase 2 (Weeks 5-8): SMB Feature Parity
1. Ship search/tags/filters.
2. Add drafts/autosave/scheduled publish.
3. Build admin analytics (engagement + investment metrics).
4. Add integration layer (webhooks + Slack/Teams + CSV).

### Phase 3 (Weeks 9-12): Go-to-Market
1. Define packaging and usage limits.
2. Add billing and trial flow.
3. Publish landing page + security one-pager + onboarding playbook.
4. Run 3-5 SMB design partner pilots with success KPIs.

## 5) Pricing and Packaging Suggestion

### Core
- Internal blogging, comments, moderation baseline, search, basic analytics

### Growth
- Core + investment governance, advanced analytics, workflows, integrations

### Enterprise (later)
- Growth + SSO/SCIM, advanced permissions, white-label, compliance features

## 6) Pilot Success Metrics

1. Time to first post (activation)
2. Weekly active readers/authors
3. Comment participation rate
4. Investment participation rate
5. 30-day team retention

## 7) Key Risks to Validate Early

1. Whether investment workflow is a must-have beyond Astrorei
2. Whether SMB buyers prioritize innovation tooling over generic internal comms
3. Whether security/compliance expectations block sales without SSO and audit maturity
